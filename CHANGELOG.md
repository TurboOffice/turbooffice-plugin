# Changelog

## 1.2.0

- The assistant can start an offer, a counter or an amendment, a listing, a buyer agreement, a deal's agreement or disclosure, a form, a signing, and a CMA. TurboOffice writes the paper.
- The assistant can ask for a change to a draft or a CMA it started.
- Paper someone has already signed, from either side, can be opened for the signatures it still needs.
- Nothing goes out for signatures until the agent approves it.

## 1.1.2

- Claude's listing uses the same icon file as the other hosts, and nothing in the plugin keeps a second copy.
- The Claude ZIP includes the icon.

## 1.1.1

- Review materials for the ChatGPT listing.
- The Cursor manifest carries a category and tags, and its author follows Cursor's schema. Install steps for Cursor and Grok Bot.

## 1.1.0

- A deal's paper shows who is seated on it and which offer it belongs to, so the assistant can say where an offer stands before anyone has signed.
- A draft opens as it stands, with what has been filled in so far.
- Feedback to the TurboOffice team goes only when the agent asks for it.
- Preparing a signed offer for the other side's signatures prepares the signing packet; nothing goes out until the agent sends it.

## 1.0.0

- First release: the skills generated from the TurboOffice server, and the remote MCP server at `https://turbooffice.ai/mcp`.
